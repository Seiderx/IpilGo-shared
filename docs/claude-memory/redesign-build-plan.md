## Decisions (2026-10-29)
- User approved the plan as written.
- Style: modern, minimalistic, "quiet premium" like viral web designs (Linear/Stripe/Apple/Airbnb). NOT colorful, NO gradients, NO 3D. Neutrals + one restrained accent.
- Icons uniform: Lucide only, one stroke weight, sizes 16/20/24, one color, never filled, no tinted circles behind icons. See [[ui-redesign-direction]].
- Dark mode: YES — user wants a dark mode feature too (clarified 2026-10-29). D2 tokens must define light + dark themes; follow system setting with a manual Light/Dark/System switch in Profile; mockups in D1 should show both.
- Photos are the hero. 360° panoramas were the original idea; now mostly regular photos only — design must look great with plain photos, keep 360 viewer working where a spot has one (destinations.panoramic_360_url).
- User shared reference photos: a small green island with white-sand spit in deep blue sea, and the Zamboanga Sibugay provincial capitol (terracotta/salmon roofs, cream walls, sea behind). Possible restrained palette cue: sand/off-white neutrals, deep sea blue or terracotta as the single accent.
- Redesign changes look only — no features removed. Follow [[cross-app-parity]].

**Why:** user wants the apps to not look AI-built for the thesis panel/public.
